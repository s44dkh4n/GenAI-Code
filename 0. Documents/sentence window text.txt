1. Introduction to Sequence Modeling
The dominant sequence transduction models relied heavily on complex recurrent neural networks (RNNs) or gated recurrent units (GRUs) arranged in encoder-decoder configurations. These recurrent models process text sequentially, factoring computation along the symbol positions of input and output sequences. Aligning the positions to steps in computation time creates a fundamental constraint that precludes parallelization within training examples. This bottleneck becomes critical at longer sequence lengths, as memory constraints limit batching across examples. Recent efforts introduced attention mechanisms in conjunction with recurrent networks, but the underlying sequential constraint remained.

2. The Transformer Architecture Core
The Transformer model architecture dispenses with recurrence and convolutions entirely, relying solely on self-attention mechanisms to draw global dependencies between input and output. By eliminating sequential operations, the Transformer allows for significantly more parallelization and drastically reduces training time. The standard Transformer follows an encoder-decoder structure where both components are constructed from stacks of identical layers. The encoder processes an input sequence of symbol representations into a continuous representation, which is then fed into the decoder. The decoder generates an output sequence of symbols one element at a time in an auto-regressive manner.

3. Encoder and Decoder Stacks
The encoder is composed of a stack of N = 6 identical layers. Each individual layer contains two main sub-layers: a multi-head self-attention mechanism and a simple, position-wise fully connected feed-forward network. Around each of these two sub-layers, residual connections are employed, followed by layer normalization. This means the output of each sub-layer is LayerNorm(x + SubLayer(x)). To facilitate these residual connections, all sub-layers in the model, including the embedding layers, produce outputs of dimension d_model = 512. The decoder is also composed of a stack of N = 6 identical layers. However, in addition to the two sub-layers present in each encoder layer, the decoder inserts a third sub-layer, which performs multi-head attention over the output of the encoder stack. The self-attention sub-layers in the decoder are also modified to prevent positions from attending to subsequent positions. This masking ensures that the predictions for position i can depend only on the known outputs at positions less than i.

4. Attention Mechanisms and Scaled Dot-Product
An attention function can be described mathematically as mapping a query and a set of key-value pairs to an output vector. The output is computed as a weighted sum of the values, where the weight assigned to each value is computed by a compatibility function of the query with the corresponding key. Scaled Dot-Product Attention is the core building block of this model. The input consists of queries and keys of dimension d_k, and values of dimension d_v. The dot products of the query with all keys are computed, divided by the square root of d_k, and passed through a softmax function to obtain the attention weights. In practice, the attention function is computed on a set of queries simultaneously, packed together into a matrix Q. The keys and values are packed into matrices K and V respectively. The mathematical formula is defined as Attention(Q, K, V) = softmax((Q * K^T) / sqrt(d_k)) * V.

5. Multi-Head Attention Strategies
Instead of performing a single attention function with d_model-dimensional keys, values, and queries, multi-head attention linearly projects the queries, keys, and values h times with different, learned linear projections. For the standard Transformer, h = 8 parallel attention layers, or heads, are used. On each of these projected versions of queries, keys, and values, the attention function is performed in parallel, yielding d_v = 64 dimensional output values. These outputs are concatenated and once again projected, resulting in the final values. Multi-head attention allows the model to jointly attend to information from different representation subspaces at different positions. With a single attention head, spatial averaging inhibits this capacity.

6. Positional Encodings
Since the Transformer contains no recurrence and no convolution, it has no inherent sense of sequence order or relative token position. To allow the model to make use of the order of the sequence, positional information must be injected into the input embeddings. The Transformer uses positional encodings added directly to the input embeddings at the bottoms of the encoder and decoder stacks. The positional encodings have the same dimension d_model = 512 as the embeddings, so the two can be summed together. Sine and cosine functions of different frequencies are chosen for this task. The formula uses PE(pos, 2i) = sin(pos / 10000^(2i/d_model)) and PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model)). This specific design was chosen because it allows the model to easily learn to attend by relative positions, since for any fixed offset k, PE(pos+k) can be represented as a linear function of PE(pos).
